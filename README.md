# 구월중학교 교실배치도 (휴대폰용)

- 주소: https://j333333766-hub.github.io/guwol-classroom-map/
- 교실을 누르면 길찾기(엘리베이터 여부 → 입구 → 경로). 길찾기 경로는 수능 안내판(11/2)과 같음: 중앙 입구에서는 가운데 계단, 층간 이동·연결통로도 선으로 이어 그림.
- 휴대폰: 두 손가락 확대, 오른쪽 아래 −/맞춤/+ 단추, 경로가 나오면 전체 보기로 돌아가고 경로 설명을 펼침.
- 휴대폰(700px 이하) 길찾기: 층별 단계로 나누어 확대해 보여 줌(이전·다음·전체 지도 보기). `map-steps.js`·`map-steps.css`는 수능 앱 것과 같음.
- 길찾기 주소 공유: 경로가 나오면 주소창이 `?to=교실&lift=1|0&from=입구번호`로 바뀌고 [길찾기 주소 공유] 단추로 보냄. `to`는 교실 id(room-55) 또는 이름(3-5), `lift=1`은 엘리베이터(② 중앙 입구 출발), `lift=0`은 계단+`from`(1~4) 입구. `from`이 없으면 입구 고르기, `lift`가 없으면 엘리베이터 질문부터.
- 편집·버전 기능은 주소 끝에 `?edit=1`을 붙였을 때만 보임.
